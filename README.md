A one-line weather forecast for Mistwick, a city that does not exist, where the fog runs on a timetable like a bus: it arrives at 7:12 sharp and leaves at 8:05, so commuters check the fog times before their bus times — and when the 7:40 fog is cancelled, the 8:10 mist is the only service left. Written in real broadcast-forecast rhythm, for a bored commuter at a rainy bus stop.

## Run it

```sh
python3 main.py
```

This writes the forecast line to `/output/entry.txt` (and, best effort, a copy at `entry.txt` in the repo root).
